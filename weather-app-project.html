Weather Forecast Application Project

The Weather Application project was coded using React.js and was built as part of the SheCodes Junior Front End Developer certification. The project uses the SheCodes API to fetch to display the weather for the searched city, displaying the 5-day forcast with animations. The design is simple and clean, with a focus on readability and user experience.
