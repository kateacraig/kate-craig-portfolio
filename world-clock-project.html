World Clock Application Project

Check out the GitHub Repository for this site.

The World Clock Application project was coded using HTML+CSS and JavaScript and was built as part of the SheCodes Junior Front End Developer certification. The application uses the SheCodes API to fetch to display the time for a pre set list of cities as well as a dropdown to select additional cities. The design is simple and clean, with a focus on readability and user experience.
