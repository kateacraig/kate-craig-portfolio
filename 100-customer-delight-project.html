100% Customer Delight Website Page Project

Check out the GitHub Repository for this site.

The 100% Customer Delight Website Page Project was coded using Claude to design the page in Figma and then after the customer approved the design, using Claude Code to take the Figma design and write the PHP and CSS to add to the customer WordPress theme for the McClaskey Excellence Institute page. Due to the integration of AI and LLMs in development, I used these tools to develop and design with my oversight. I wrote the prompts and used Claude to refine the Figma design, with customer changes. And then wrote the prompt to integrate the designs CSS into the existing CSS as well as to write the PHP template to add to the WordPress website. I used Claude to match the existing mobile breakpoints for the site to ensure seamless mobile responsiveness. Additionally, I used Claude match the styling for the website page from the 100% Customer Delight book cover designers.
